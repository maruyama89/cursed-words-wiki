# 用語集

Cursed Words: The Word Game That Isn't に登場する未日本語化の用語・システム名などをまとめる。

訳語は私訳（非公式）。確定していないものは「訳案」欄に候補を書き、確定次第ここを更新する。

## 使い方
- 原語（英語表記）はゲーム内表記に正確に合わせる（大文字小文字・スペルも含む）
- 「初出/文脈」には、どの場面・メニュー・カード等で見た用語かを書く（後で探しやすくするため）
- 未確認・推測の説明には必ず「（要確認）」を付ける
